# intermediate-elective
ENVS19DS repository for intermediate elective

## General information

This repository contains data and code to explore longer term trends in bird group observation counts at North Campus Open Space. 

To work with the code in this repository, you will need the following packages:

```
library(tidyverse)
library(janitor)
library(here)
library(scales)
library(NatParksPalettes)
library(ggrepel)
```
